# 05 — Stories & Reels (9:16)

Format vertical plein écran. **Règle de composition :** garde le tiers central
propre. C'est là que tu poseras le produit, le texte ou ton visage.

Instagram masque aussi les bords : prévois **250 px de marge en haut** (nom du
compte) et **250 px en bas** (barre de réponse). Ne mets rien d'important là.

## Le script du reel qui marche

Structure éprouvée, 40 secondes. Sous-titres **toujours** : la majorité regarde
sans le son.

```
0–3 s    ACCROCHE — image + phrase, en même temps
         Ex. : « Ton parfum disparaît en 2 heures ? C'est pas le parfum. »

3–10 s   LE PROBLÈME — pourquoi ça arrive
         « La plupart des gens le mettent au mauvais endroit. »

10–25 s  LA VALEUR — une seule idée, montrée
         Les 3 notes, ou les 3 points de pulsation. Pas plus.

25–35 s  LA PREUVE — montre, n'affirme pas
         Le batch code, la facture, le colis, un vrai message client.

35–40 s  L'APPEL — un seul, précis
         « Écris ORIGINAL en DM pour le prix. »
```

**Une seule action par vidéo.** « DM ou WhatsApp ou lien en bio » ne convertit
rien : trois choix, c'est zéro décision.

### Cinq accroches à réutiliser

| Type | Accroche |
|---|---|
| Contradiction | Le parfum cher n'est pas toujours le meilleur — voilà pourquoi. |
| Question qui engage | Ton parfum est-il vraiment original ? Regarde ça sur le flacon. |
| Chiffre | 3 parfums sous 500 dh qui tiennent plus longtemps que des parfums à 2000. |
| Erreur | Presque tout le monde applique son parfum au mauvais endroit. |
| Démonstration | *(aucune parole — tu ouvres sur le geste : le batch code sous la lumière)* |

Ne commence **jamais** par « Salam, aujourd'hui je vais vous parler de… ».
C'est précisément à cette seconde que le spectateur part.
